# линк в апе, маков нет (случай 3520)
	⁃	конфиг порта, чтобы там был pvid dhcp
	⁃	проверяем pppoe настройки на порту (show running config int port channel 4) - две строки
	⁃	ребут порта для профилактики - появился dhcp mac
	⁃	axiros - настраиваем роутер: накатываем pppoe настройки на роутере

# не показывает IPTV
	1.	проверить подписку: statistics igmpsnoop port group 33
	2.	проверить параметры по линии: adsl linerate 33
	3.	проверить пропускную способность именно по линии тв: statistics port 33 1 32
	4.	проверить пропускную способность именно по линии интернета: statistics port 33 0 33
	5.	проверить логи на наличие петли или обрыва (run...)
	6.	если все в порядке, проблема в: источнике входа в тв (source, input), кабели, или в самом терминале

# если нет подписки IPTV / прерывается IPTV / много подписок IPTV
	1.	попросить выключить терминал и тв
	2.	adsl pvc delete 36 1 32
	3.	adsl pvc set 36 1 32 super DEFVAL
	4.	config save
	5.	включить тв и ожидать 2-3 минуты

# ошибки IPTV
400 - не подключен кабель к тв приставке
401 - нет сигнала. переподкл кабель или тп3
402 - проблема подключения кабеля приставка / роутер
403 - проблема со временем. помогает перезагрузка
404 - помогает перезагрузка

# нет логина (юрик)
	⁃	берем лицевой счет и находим его через ирбис
	⁃	достаем его влан
	⁃	узнаем какие порты заняты этим вланом
	⁃	смотрим эти порты на оживленность
	⁃	смотрим какие маки на этих портах
	⁃	смотрим (маки свыше) все мак адреса по этому влану

# статический IP (нету логина)
	1.	заходим на ПЕшку: в конце IP железки ставим "1": 10.222.22.27 -> 10.222.22.1
	2.	находим нашего клиента по его влану и достаем его наименование: show interfaces description | include <vlan>
	3.	смотрим его IP-адреса: show interfaces "наименование"
	4.	видим два IP-адреса: меньший - шлюз, больший - IP. 

# юрик / бигпенсил - необходимо находить кл по влану
	1.	достается влан через ирбис
	2.	зайти на пм
	3.	посмотреть по влану: аплинк и порт(ы) клиента
	4.	проверить порт(ы) на работоспособность как обычно
